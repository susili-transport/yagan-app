야간반납 각서 자동생성

설치·서버 없이 브라우저에서 바로 사용하는 버전 · 담당자별 입력 → 취합 → 각서 자동생성

엑셀에서 여러 건 한번에 붙여넣기 (권장)

본인 엑셀 파일에서 표(제목행 포함 또는 미포함 모두 가능)를 마우스로 드래그해서 선택 → Ctrl+C → 아래 칸을 클릭하고 Ctrl+V로 붙여넣기 → 버튼 클릭.

담당자마다 엑셀 열 구성이 달라도 괜찮습니다. 제목행에 "날짜/선사/컨테이너/사이즈/상차지/하차지/내품" 같은 이름이 있으면 순서와 상관없이 자동으로 인식합니다. 제목행이 없다면 날짜, 선사, 컨테이너, 사이즈, 상차지, 하차지, 내품, (선택)운행여부, (선택)요청운송사 순서로 붙여넣은 것으로 간주합니다. 앞의 7개 항목은 필수이며, 값이 없는 행은 건너뜁니다 (등록자·운행여부·요청운송사는 입력 안 해도 빈칸으로 처리됩니다). 오늘 날짜() 항목만 자동으로 들어가고, 엑셀에 다른 날짜 기록이 섞여 있어도 자동으로 걸러집니다.

한 건씩 직접 입력

담당자 각자 자신의 브라우저에서 입력하세요. 입력한 내용은 이 브라우저에만 자동 저장됩니다(다른 사람 화면과 공유되지 않음). * 표시는 필수 항목입니다.

참고: 사이즈는 자동으로 정리됩니다 — 40R/40RF/40RE 같은 리퍼 계열은 40R로, 40HC/40H/20DC 같은 나머지는 숫자만(40, 20)으로 저장됩니다. 선사 HAS + 리퍼 사이즈(40R/20R)는 입력이 차단됩니다. 하루 총 10건, 선사 SKR+리퍼 사이즈는 하루 2건을 넘으면 경고가 표시됩니다(입력 자체는 막지 않음).

내가 입력한 오늘 리스트 (0건)

구글시트로 전송이 설정되어 있으면 그 버튼 하나로 취합 담당자에게 바로 전달됩니다 (설정 탭 참고). 설정하지 않았다면 JSON 내보내기 파일을 카카오톡/메일 등으로 직접 전송하세요.

아직 입력한 항목이 없습니다.

구글시트에서 자동 취합 (권장)

설정 탭에 구글시트 연동 URL을 등록해두면, 담당자들이 파일을 보내지 않아도 아래 버튼 한 번으로 그동안 접수된 모든 항목을 가져올 수 있습니다.

담당자들이 보낸 파일 가져오기 (구글시트 연동을 안 쓸 경우)

여러 담당자가 보낸 JSON 파일을 한 번에 선택하면 자동으로 합쳐집니다. 엑셀(.xlsx)이나 CSV 파일도 가져올 수 있습니다. (엑셀/CSV는 '날짜'와 '컨테이너' 등 열 제목이 있는 표 형태여야 자동으로 인식됩니다.)

엑셀(.xlsx) 가져오기/내보내기 기능은 외부 변환 라이브러리를 사용하므로, 이 페이지를 처음 열 때 인터넷 연결이 필요합니다. JSON/CSV 기능은 인터넷 없이도 동작합니다.

취합된 전체 리스트 (0건)

아직 취합된 항목이 없습니다.

각서 생성 조건

해당 날짜의 취합 리스트 전체를 10건 단위로 나누어 문서를 생성합니다. 10건이 넘으면 문서가 여러 장으로 자동 분할됩니다.

각서 문구는 사용자가 제공한 기존 Word 템플릿(야간반납 확인각서(부산사무소).doc)의 실제 문구를 그대로 사용했습니다. 다만 법적 효력이나 문구의 최종 적합성은 이 앱이 보증하지 않습니다. 회사 양식 및 법무 기준에 맞는지 실제 발송 전 반드시 직접 확인하세요. [확인 필요]

기본 정보 설정

여기 입력한 값은 이 브라우저에 저장되며, 각서 생성 시 기본값으로 자동 채워집니다. 담당자 이름·연락처 등 개인정보이므로 본인이 직접 입력하세요.

구글시트 자동연동 (선택)

이 URL을 등록하면 파일을 직접 주고받지 않아도, 입력 탭에서 바로 공유 구글시트로 전송하고 취합 탭에서 새로고침만으로 최신 데이터를 받아올 수 있습니다. 무료 Google Apps Script로 직접 만들 수 있으며, 만드는 방법은 채팅으로 안내해드립니다. 비워두면 기존처럼 파일로 직접 주고받는 방식이 그대로 사용됩니다.

이 URL을 아는 사람은 누구나 연동된 구글시트를 읽고 쓸 수 있습니다. 관련 없는 사람에게 공유하지 마세요. [확인 필요: 회사 보안 정책상 이 정도 접근 범위가 괜찮은지 검토 필요]

위 URL도 기본 정보 설정 카드의 "저장" 버튼을 누르면 같이 저장됩니다.
